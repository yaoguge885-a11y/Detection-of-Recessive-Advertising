# MMM 2027 研究型论文选题建议

> 更新时间：2026 年 7 月 17 日。本文用于**确定研究论文的核心科学问题**，而不是把完整系统蓝图原样写成论文题目。每个候选方向都应满足：提出可证伪假设、给出可复现算法、与强基线比较，并通过消融实验论证各模块的价值。

## 1. MMM 2027 对本项目的启示

MMM 2027 的常规论文投稿截止日期为 **2026 年 8 月 16 日**，会议采用英语论文、论文集模板与双盲评审要求。和本项目直接匹配的方向包括：

- Multimedia Content Analysis：多模态分析与语义理解、上下文感知分析、验证与融合；
- Multimedia Applications / Services：多媒体分析、多模态问答与会话式 AI、个性化；
- Ethical, Legal and Societal Aspects：公平、问责、透明性、可解释性、鲁棒性与负责任多媒体建模；
- Emerging Topics：多媒体大模型/LLM、多模态预训练与表征学习；
- “Multimodal Agentic Systems: Foundations, Architectures, and Applications”专题分会：智能体记忆机制、证据溯源、可解释与可信系统等。

**写作定位建议：** 论文的创新点应落在一个可训练、可评估的检测方法上；LangGraph、多智能体、RAG 和 Web 演示系统可作为实现与应用场景，不宜取代算法贡献本身。

## 2. 选题筛选原则

1. **题目聚焦一个主张。** 例如“长期人设偏移有效”或“图文语义冲突有效”，不要在一篇短论文里同时承诺记忆、OCR、评论 GNN、RAG、辩论、法规等全部模块。
2. **标签应为三元。** 统一评估“明广 / 暗广 / 非广”，并将“暗广”作为主要报告类别。
3. **按博主切分和按时间切分。** 同一博主历史帖不得同时落入训练和测试；还应检验面对新时间段/新套路时的泛化。
4. **传统基线 + 多模态基线 + 去模块消融缺一不可。** 可保留申报书中的 XGBoost 作为传统融合基线，再与单帖文本、单帖图文、多模态模型比较。
5. **证据解释必须可评。** 除 P/R/F1、AUC 外，报告暗广 Recall、ECE/Brier 等校准指标，以及人工评估的证据相关性/可读性。

## 3. 候选题目与可检验研究设计

### A. 首选：长期人设记忆与偏好偏移

**英文题目**  
`PersonaDrift: Longitudinal Creator Memory and Preference-Shift Modeling for Explainable Implicit Advertising Detection`

**中文题目**  
`PersonaDrift：面向可解释隐性广告识别的博主长期人设记忆与偏好偏移建模`

**核心假设 H1**  
对于同一博主，暗广帖在“内容主题—商业意图—商品视觉显著性—语言风格”的联合行为轨迹上，比明广和非广更容易出现可量化的短期偏移；引入时间衰减的博主历史记忆，可显著提升暗广识别与跨时间泛化能力。

**方法主线**

1. 用文本、图片/OCR、商品/Logo 线索抽取每条帖子的多模态表征；
2. 为每个博主构建多尺度长期记忆：短窗口、长窗口和稳定人设原型；
3. 用 EMA 原型差、JS 散度/变化点分数、商业意图残差等生成“偏移证据”；
4. 以时间感知门控融合当前帖与历史偏移特征，输出三元类别、置信度和可追溯证据；
5. 将 Agent 限定为“按需取历史、调工具、整理证据”的系统层，不把提示词流程包装成主要算法创新。

**关键对比与消融**

- 单帖文本模型、单帖图文模型、传统特征 + XGBoost；
- 无历史 / 随机历史 / 不带时间衰减历史 / 完整长期记忆；
- 仅主题偏移 / 仅视觉商品偏移 / 仅文本商业意图 / 联合偏移；
- 随机切分、按博主切分、按时间切分三种协议。

**优点与风险**  
该题最能体现项目已有的“博主长期记忆 + 偏好偏移 + 证据链”特色，且比完整多智能体系统更容易形成清晰假设。主要风险是需要同一博主的连续历史帖；因此 P1 必须优先设计“博主 ID、时间戳、图文、三元标签”的数据结构。

### B. 次选：图文不一致与局部商品显著性

**英文题目**  
`InconAd: Fine-Grained Cross-Modal Incongruity Contrastive Learning for Implicit Advertising Detection`

**中文题目**  
`InconAd：面向隐性广告识别的细粒度图文语义冲突对比学习`

**核心假设 H2**  
暗广常通过“生活化/情绪化文本”与“局部高显著商品、Logo、规格或导购文字”之间的跨模态不一致来规避直接推广表述；显式建模句子—图像区域—OCR 词元的细粒度冲突，比全局图文相似度更能识别此类暗广。

**方法主线**

1. 切分文本句子/情感与商业意图单元，提取图片 patch、商品区域和 OCR 词元；
2. 进行 patch–word、region–sentence、global–post 三层对齐；
3. 构造困难负样本：同文换图、同图换文、遮挡商品区域、去除 OCR 等；
4. 用“语义对齐损失 + 冲突排序/对比损失 + 三元分类损失”联合训练；
5. 输出冲突热图与对应文本片段，作为可解释证据。

**关键对比与消融**

- CLIP 全局相似度、早期拼接、多模态 Transformer；
- 不同粒度对齐（仅全局 / 句图 / 区域词 / 三层）；
- 无困难负样本、无 OCR、无商品显著性分支；
- 原始样本与人工构造反事实样本上的鲁棒性。

**优点与风险**  
与 MMM 的“multimodal analysis and semantic understanding / verification and fusion”高度贴合，视觉化结果好展示。风险是需要可靠的商品区域、OCR 或冲突样本；若标注资源不足，可先选择“有明显商品线索”的子集或使用弱监督候选区域。

### C. 系统型方向：可靠性校准的智能体证据融合

**英文题目**  
`RouteAd: Reliability-Calibrated Agentic Evidence Fusion for Explainable Implicit Advertising Detection`

**中文题目**  
`RouteAd：面向可解释隐性广告识别的可靠性校准智能体证据融合`

**核心假设 H3**  
不同帖子对文本、视觉、历史行为和法规检索的依赖不同。以验证集性能、输入质量和跨智能体一致性为依据进行可靠性校准和动态路由，能够在相同或更低调用成本下提高暗广 F1、置信度校准与证据质量。

**方法主线**

1. 文本、视觉、行为和检索模块分别产生结构化证据与不确定性；
2. 学习/估计每个模块的条件可靠度，而非固定平均投票；
3. 用路由策略决定是否调用视觉、历史或 RAG 工具；
4. 由校准聚合器输出三元判定、置信区间、证据贡献和人工复核建议。

**关键对比与消融**

- 单一多模态大模型、固定顺序 Agent、固定加权投票、完整全调用；
- 动态路由 vs 全部调用：F1、召回、Token/时延、ECE/Brier、人工证据评分；
- 去掉可靠度校准、去掉一致性检查、去掉某一专家模块。

**优点与风险**  
最贴近“Multimodal Agentic Systems”专题分会，也能直接复用现有 LangGraph 骨架。风险是容易写成工程整合，必须把“可靠度估计/校准聚合/成本—性能曲线”做成严格算法与实验，而不是只展示工作流。

### D. 进阶融合题：历史引导的跨模态冲突检测

**英文题目**  
`MemAlign: History-Guided Multi-Granular Cross-Modal Incongruity Learning for Implicit Advertising Detection`

**中文题目**  
`MemAlign：面向隐性广告识别的历史记忆引导多粒度图文语义冲突学习`

**核心假设 H4**  
同一条图文内容是否“异常”，需要同时相对于其内部图文语义和博主长期人设进行判断；历史记忆可以减少把正常生活分享误判为暗广的情况。

**取舍说明**  
该方向将 A、B 融合，理论上创新空间较大，但对数据、模型和消融要求也最高。若 2026 年 8 月 16 日前无法完成连续历史数据与细粒度商品/冲突标注，不建议将它作为首投主线。

## 4. 推荐结论

**建议将 A（PersonaDrift）确定为主选题，将 B（InconAd）作为可独立投稿或主论文的视觉子模块储备。**

原因：

- A 直接利用项目最有辨识度、也最难被普通单帖检测器替代的长期行为信号；
- A 的数据与算法边界可控，能先完成一个独立可训练的模型，再接入 Agent 演示；
- B 的跨模态对比/注意力方法可作为 A 的图文特征提取器或后续第二篇论文；
- C 更适合在 A/B 有稳定专家模型以后，做系统论文或专题分会投稿；
- D 不宜在首轮开发中承担全部风险。

## 5. 从选题到可投稿论文的最小执行清单

1. **一周内定数据协议：** 每条记录至少包括 `post_id`、`blogger_id`、`timestamp`、文本、图片/图片链接、OCR、三元标签、标注理由；优先保证同博主连续历史。
2. **先写假设和评测协议：** 在采集大量数据前明确按博主/时间切分，避免同博主信息泄漏。
3. **两周内跑出基线：** 文本、图文、传统融合三类基线都需能输出暗广类别指标。
4. **只实现一个主创新：** 先完成时间衰减记忆和偏移量化，再决定是否加入复杂多智能体、RAG、OCR 或 Logo 检测。
5. **论文实验最少包含：** 主结果、类别结果、按博主/时间泛化、消融、误差案例、证据解释人评或定量代理指标。
6. **投稿前检查：** 使用官方模板，英语撰写，按双盲要求移除作者可识别信息；会议的常规论文截止日期是 **2026 年 8 月 16 日**。

## 7. 不建议采用的题目表述

- “基于多智能体的隐性广告识别系统研究”：范围太大、算法主张不明确，容易变成系统说明。
- “基于图文不一致的暗广识别”：太泛，需明确细粒度单元、冲突定义和对比损失/学习目标。
- “基于长期人设记忆的暗广识别”：方向正确，但需补足“长期记忆如何表示、偏移如何量化、为何能泛化”。

因此，首选题目的关键词建议固定为：**Longitudinal Creator Memory / Preference Shift / Explainable Implicit Advertising Detection**。
