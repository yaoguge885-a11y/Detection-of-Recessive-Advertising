### 2.2 Qwen 辅助标注的诊断和修复（本地新增，尚未上传代码）

针对模型与人工判断分歧，已完成稳定复现、根因分析及最小修复，主要包括：

- 让 `uncertain` 正确保留，非法标签不再自动变成“非广”。
- 将完整标注指南、评论与媒体/采集状态传入模型；证据不足时转人工判断。
- 明确上下文参数，记录模型来源、fallback、错误、原始与规范化标签、输入和代码哈希。
- 增加固定样本清单、人工媒体查看审计、A/B 独立 HTML 标注及导出工具。

2026-08-25 的原 20 条真实 Ollama 回归：20 条均调用到 Ollama，fallback 和 error 均为 0；**20 条全部输出 `uncertain` 并转人工**。这证明修复后能显式处理证据不足，但尚不能证明辅助标注有效；在该次无图像输入、采集完整性未知的条件下，没有减少人工判断负担。

随后准备了全新 21 条盲测。2026-08-27 的 remote-links v2 保留同一批样本与顺序，修复了人工视频查看入口：

- 67 个本地固定媒体；
- 7 个受限在线源视频入口；
- A/B 各自的 HTML 与便携压缩包均已生成；
- 在线视频未固定在包内，需由人工如实记录是否可访问和已查看。

**截至本次核查，标准交付目录未见两份完整 A/B 盲测结果、裁决和裁决后 Qwen 对照。** 当前状态仍是 `engineering_fixed_quality_pending_human_blind_test`，即工程修复完成、质量验收待人工；不能标记 Qwen 工作流结束。

### 2.3 系统、研究框架和网页

仓库已经实现以下功能：

- 输入统一为 `PostRecord/CaptureStatus`，通过能力规划调用文本意图、情绪、OCR、图文一致性、商品/Logo、主题漂移、评论异常等 7 个工具。
- 统一生成 `EvidenceBundle`，先判断信息是否充分，再区分商业意图与广告披露，输出明广 / 暗广 / 非广或需复核。
- 本地与 MCP 调用复用工具，具备超时、回落和运行轨迹；法规 RAG 提供有来源的引用。
- API、CLI 与网页复用同一分析服务，支持单条、批量、运行记录查询、证据展示和报告下载。
- CreatorShift 已有“仅使用目标帖之前、同创作者历史”的工程边界，以及简单历史池化与独立 Logistic Regression 基线；真实模型增益尚未验证。
- P3 分支完成小红书 normal/video、B站 video/opus/article 共 5 个结构仿真案例适配，及 URL、媒体路径、输出脱敏、工具权限等安全工程检查。默认平台能力仍未开放为真实采集服务。
