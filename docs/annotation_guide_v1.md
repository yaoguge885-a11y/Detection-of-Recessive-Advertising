# 隐性广告人工标注指南 v1.0

## 1. 适用范围

本指南用于社交媒体帖子级人工标注。标注对象是当前帖子及本次采集到的正文、图片、评论、页面商业标识和必要的创作者历史证据。不得用“像广告”“账号变化大”或“没有抓到披露”单独定类。

核心标签：

| 标签 | 判定条件 |
|---|---|
| 明广 | 有充分商业推广意图证据，并有明确广告、赞助、合作、赠送或平台商业标识 |
| 暗广 | 有充分商业推广意图证据；相关披露区域已完整采集，仍未发现明确披露 |
| 非广 | 没有足够证据支持商业推广意图 |
| uncertain | 证据缺失、冲突或质量不足，当前无法可靠归入三元标签 |
| out_of_scope | 不属于本研究的商业内容推广范围 |

决策顺序：先判断是否在范围内，再判断商业推广意图，最后判断是否有明确披露。只有三元标签进入 κ 和 Gold；`uncertain` 进入复核池，`out_of_scope` 单独统计。

## 2. 证据记录

每条标注必须记录可复核证据，不得只写结论。建议证据码：

| 代码 | 含义 |
|---|---|
| D | 明确披露：广告、赞助、合作、赠送、受邀或平台商业标识 |
| C | 商业对象是内容核心 |
| P | 促销或强推荐话术 |
| A | 购买、预约、报名、搜索、私信、优惠码或二维码等转化动作 |
| V | 图像、OCR 或画面中的商业证据 |
| M | 评论区异常或导流证据 |
| B | 可验证的创作者历史变化，仅作辅助证据 |

`B` 不能单独证明商业意图。缺失的页面、评论或图像必须记为“未采集/不可读”，不能记为“未发现”。

## 3. 边界案例

### EC-01 明确“广告/赞助”字样

商业对象明确且正文或平台标签披露广告、赞助，标为明广；记录 D 和支持商业意图的证据。

### EC-02 品牌赠送或寄送

披露“品牌寄送/赠送/PR sample”且内容围绕该商品，标为明广；单纯收到朋友礼物不等同商业合作。

### EC-03 受邀发布会或探店

明确披露受品牌或商家邀请，并集中介绍其产品或服务，标为明广。

### EC-04 联合抽奖

创作者与品牌联合发起抽奖或活动且关系已披露，标为明广；只转发无商业关系的公共活动需另看商业意图。

### EC-05 平台商业内容标识

页面存在可验证的“商业合作/赞助”等平台标识，标为明广；截图缺失或标识区域未采集则不能假定存在。

### EC-06 专属优惠码但无披露

帖子围绕单一商品并提供专属优惠码，商业意图充分；披露区域完整且无披露时标为暗广。

### EC-07 链接藏在置顶评论

正文强推荐、置顶评论提供购买链接，商业意图充分；无明确披露且评论采集完整时标为暗广。

### EC-08 图片二维码或领券信息

正文自然但图片含商品、促销和扫码领券信息，图像可读且无披露时标为暗广；图像不可读则标 uncertain。

### EC-09 暗号折扣或私信导流

出现“报暗号”“私信领取”“到店出示”等可执行转化动作，结合明确商业对象可支持暗广。

### EC-10 比较内容只导向一个购买入口

表面比较多个产品，但结论和链接只导向单一商品，且无披露时可标暗广；平衡比较且无导流通常为非广。

### EC-11 稀缺、价格和限时促销

库存、到手价、限时优惠与购买动作共同出现可支持商业意图；新闻报道中的价格事实不能单独支持。

### EC-12 评论区模板化赞美

重复、集中、模板化评论只作辅助证据 M；没有内容核心、促销或转化证据时不得单独标暗广。

### EC-13 搜索直播间或店铺

明确引导搜索特定直播间、店铺或商品并说明赠品/优惠，无披露时可标暗广。

### EC-14 创作者主题突然变化

可验证的历史主题变化只记录 B；必须同时存在当前帖商业意图证据才能影响三元判定。

### EC-15 平衡评测含明确缺点

同时呈现优缺点、无优惠和购买入口，通常标非广；若仍有专属链接或商业披露，按其证据重新判断。

### EC-16 背景中偶然出现 Logo

Logo 不是内容核心、没有推荐或转化动作，标非广；不得因品牌露出本身判广告。

### EC-17 商品负面投诉

以维权、故障或负面体验为核心且无推广导流，标非广；品牌对象明确不等于商业推广意图。

### EC-18 新闻、科普中的价格或品牌

多品牌事实整理、新闻或科普且无偏向性购买动作，标非广。

### EC-19 日常记录中的餐厅或用品

对象只是生活记录的一部分，无折扣、强推荐、预约或链接，标非广。

### EC-20 个人二手转卖

个人闲置转卖不属于本研究的内容营销任务，标 out_of_scope；职业商家伪装个人发布需复核范围。

### EC-21 招聘、公益募集

招聘和非商业公益募集标 out_of_scope；商业课程招生或付费服务推广仍在范围内。

### EC-22 只有型号没有导流

只出现商品型号，缺少价格、优惠、链接、披露和上下文时，不强判广告；信息足够支持无商业意图则非广，否则 uncertain。

### EC-23 图片模糊或 OCR 冲突

疑似商品包装或促销文字但无法可靠识别，且正文不足，标 uncertain 并写明需补采图像。

### EC-24 披露区域或评论未采集

商业意图充分但正文首尾、平台标识区、图片或关键评论采集不完整时，披露状态为 unknown，标 uncertain；不得用“未抓到”推导暗广。

## 4. 双标、仲裁与复核

- 两名标注者独立盲标，不查看对方结果。
- κ 只基于双方均为明广、暗广、非广的共同样本。
- 分歧样本必须仲裁后才可进入 Gold；仲裁需保留最终标签、理由和仲裁者。
- 任一方为 `uncertain` 或 `out_of_scope` 时不进入 Gold。
- 置信度低于 0.6 的三元结果进入复核队列。
- 第二轮 κ 只有在指南修订后重新盲标并明确记录轮次时，才能作为 M1 正式证据。
