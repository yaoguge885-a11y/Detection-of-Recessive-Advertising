## 2 接手先按这个顺序运行

**第一步 克隆 P1 并建立环境。** 已验证环境为 Windows、Python 3.12.5；依赖使用仓库固定清单。Node 用于页面行为测试，未安装时验证报告会明确记为跳过。

```powershell
git clone --branch 'P1-·-数据地基与标注规范' --single-branch https://github.com/yaoguge885-a11y/Detection-of-Recessive-Advertising.git
cd Detection-of-Recessive-Advertising
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-handoff.txt
```

**第二步 先跑不依赖私有数据的演示。** 两个命令都不调用真实模型，不需要 API Key。

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/demo_m1_handoff.py
.\.venv\Scripts\python.exe -X utf8 scripts/demo_assisted_review.py
```

第一个演示生成 A/B 隔离盲测页面和便携包；第二个演示生成“保留已有填写、补齐空白、人工确认”的接续页。输出均使用新时间戳目录；终端提供 HTML 路径。打开页面需保持配套文件和相对路径完整。

**第三步 运行交接检查。**

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/verify_handoff.py
```

本次在干净已提交文件树上完成 12 组检查：Python **563 passed、2 skipped**，其中标注 101、传统基线 54、主系统 408；盲测页面 Node 检查 9 项、AI 接续 Node 检查 8 项通过。资产校验、合成演示与既有网页行为检查均退出码 0。两项可选视觉测试未执行，以上结果不代表真实分类效果或团队人工验收。[验证摘要](validation_2026-11-02.json)

**第四步 再接收私有包，恢复真实进度。** 完整解压 `B_私有接续_2026-11-02.zip`，先看 `README_先读.txt`，再打开根目录 `开始交接.html`。接手同学填写自己的复核人身份，检查默认显示的 14 项新增或补齐内容，有异议直接修改，逐条确认后导出。原稿的已有字段保持锁定。

私有包包含这 21 条引用的 67 个本地媒体文件、固定清单与指南、B 原稿、批准候选及必要历史记录，另有单独标识的未完成实验草稿。**它不包含全部研究媒体、完整原始快照或 A 的新 21 条原始回传包**。需要完整数据治理、全池媒体审计或正式大批次标注时，应先向数据保管人取得其余材料并核对指纹。

需要将私有数据放进克隆仓库时，按包内相对路径补入同名 `data/` 位置，先核对版本，不覆盖不同材料。真实内容继续受 Git 忽略规则保护，不随普通代码提交上传。
