# P5.7 Security Boundary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the P5.7 engineering security gate before any real platform URL is enabled, with executable controls for redirect/DNS safety, untrusted content, media references, remote capability authorization, and artifact secrecy.

**Architecture:** Put enforcement at five shared boundaries: a pinned-address redirect-safe fetcher, a URL-import media policy, an untrusted-content message envelope, a protocol-neutral remote capability policy used by MCP and fake-A2A tests, and a recursive outbound redactor used by API/report/run persistence. Security-policy violations fail closed; only genuine transport failures may use an audited local fallback.

**Tech Stack:** Python 3.10+, Pydantic v2, LangChain message contracts, pytest, stdlib `socket`/`ipaddress`/`pathlib`/`urllib.parse`; no new dependency and no live network access in tests.

## Global Constraints

- Preserve the approved boundary A: fake A2A transport security tests only; do not implement or claim P5.5 remote A2A.
- Do not contact Xiaohongshu, Bilibili, or any public URL during implementation or verification.
- Keep the default adapter registry network-disabled and the default zero-key analysis path intact.
- Maximum redirects: 5. Per-hop timeout: 10 seconds. Final page size: 5 MiB. Remote structured result size: 1 MiB.
- Existing MCP default timeout remains 30 seconds; a shorter positive `RunContext.timeout_seconds` takes precedence.
- Policy, authorization, identity, schema, and media violations fail closed and never trigger local fallback.
- Only timeout, connection, process, or EOF transport failures may trigger the existing audited MCP local fallback.
- URL-import media policy must not remove manual-input support for user-selected local images.
- All API/export, readable-report, run JSON, public error, and scanner output must exclude Cookie, Token, authorization values, and original sensitive URLs.
- Preserve unrelated uncommitted P4/P5.2 and user changes. Stage and commit only files named by the active task.
- Keep engineering completion separate from P5.5, M1, M4, and M5 acceptance.

PLATFORM_CONTENT_SYSTEM_POLICY = (
