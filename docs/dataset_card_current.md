## 3. 数据来源与用途

当前材料可用于 Schema、去重、媒体完整性、标注流程和 M1 门禁联调。未经来源条款确认、隐私人工审批和正式切分，不得公开分发，也不得用于论文级效果结论。

## 4. 标签与 Gold

目标标签为明广、暗广、非广；`uncertain` 和 `out_of_scope` 单独处理。分歧样本必须有仲裁才进入 Gold。

当前 ZIP 中没有可由 M1 审计识别的正式标注文件，正式 Gold 计数为 0。历史 pilot 的 κ=1.0 仅验证流程，缺少第二轮正式盲标证明，不能作为 M1 一致性证据；自动接受标注也不参与双人 κ。

## 5. 隐私与合规

2,901 条记录均声明 `anonymized=true`、`contains_sensitive_data=false`，但没有配套人工审批证据。审计识别出的 `terms_checked_at` 记录为 0，来源条款仍需逐平台复核。

公开发布至少需要：

- 条款核验完成且来源条款允许既定用途；
- 自动扫描结果经人工复核；
- 隐私字段与人工审批清单一致；
- 正文、URL、ID 映射和私有审查材料不进入公开仓库。

缺少任一条件时，记录只能保留在 raw 或 interim 层。

## 6. 去重与切分

正式切分必须以创作者与 `content_group_id` 的连通分量为最小单位，确保帖子、创作者和近重复内容组不跨 train/dev/test。当前没有经验证的正式无泄漏切分报告。
