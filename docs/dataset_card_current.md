canonical 中的隐私声明不替代人工证据。阶段3已完成来源条款 A/B 核验、隐私人工审批、正式候选池与复扫；正式候选池为2,932条，另有380条排除。隐私复扫的分层为 public 2,932、interim 377、raw 3；其中 `public` 仅是隐私扫描分层名称，不等于已经获得外部再分发许可。

公开发布至少需要：

- 所有后续正式批次仅从阶段3正式候选池锁定；
- 自动扫描、人工审批和正式候选集合保持一致；

缺少任一条件时，记录只能保留在 raw 或 interim 层。
