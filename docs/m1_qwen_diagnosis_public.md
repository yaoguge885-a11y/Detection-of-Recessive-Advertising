# M1 Qwen 预标注诊断与修复记录（公开聚合版）

更新：2026-09-09。本文说明工程问题、修复依据与待验证事项；逐条模型输出、样本 ID、正文、人工答案和本机诊断日志保留在受控目录。

## 为什么需要这轮工作

预标注不是简单调用模型。它连接采集证据、标注指南、模型建议、人工复核和最终数据质量。若这条链路把“证据不足”变成“非广”，即使接口成功返回，也会把系统性偏差带入 Gold 和后续实验。因此先验证输入、输出与可追溯性，再讨论是否采用模型辅助路线。

## 已定位的六类问题

| 问题 | 对研究结果的影响 | 本版处理 |
| --- | --- | --- |
| `uncertain` 与非法标签被错误归一化 | 证据不足或格式错误可能进入正式类别，改变类别分布 | 保留 `uncertain`；非法标签触发契约错误；回退与真实模型输出分别记录 |
| 完整标注指南没有稳定进入调用 | 人工与模型依据的判定规则不一致，无法公平比较 | 显式 `--guide`，记录指南 SHA-256；指南为空或缺失时停止 |
| 评论与多媒体覆盖没有充分表达 | 未检查的证据可能被误当成不存在 | 补充评论、媒体数量与来源状态；区分未启用、缺失、部分覆盖和完整覆盖 |
| 上下文参数不明确 | 长输入可能截断，复现实验缺乏固定条件 | 显式传递与记录 `--num-ctx`，默认 32768；真实模型使用情况仍以运行审计为准 |
| 阈值为 0 的语义不安全 | 关闭自动接收的意图可能变成全部自动接收 | 明确 `--auto-threshold 0` 禁用自动接收；`uncertain` 始终人工处理 |
| 日志无法完整解释输出与失败来源 | 无法区分模型判断、解析失败、回退或版本变化 | 记录原始/归一化标签、后端、回退、错误、上下文、指南哈希和时延；每条结果写入持久检查点 |

## 真实执行证据与解释边界

2026-08 的固定 20 条工程校准曾完成真实 Ollama 调用：20 条均返回 `uncertain`，未观察到调用错误或关键词回退，单条时延中位数约 69 秒。这个结果证明调用和审计链路能工作，也提示证据充分性、任务难度与模型保守性需要进一步分析。它不能说明模型分类准确率，更不能写成“Qwen 已通过质量验收”。

旧固定 20 条 A/B 复核完成的是联合机械校验：字段、样本集合与角色材料可对账。它不替代 A/B 对最终模型路线的共同签字。新 21 条盲测已准备角色隔离的 v2 页面与便携包，材料包含 67 个本地媒体引用和 7 个受限源视频入口；尚未形成可核验的 A/B 答案、仲裁与最终质量结论。

## 本次 P1 整合补充的可靠性工作

- 保留 P1 的并行执行能力，按固定清单顺序落盘；最多只保持配置数量的任务在执行队列内。
- 检查点绑定输入、指南、样本清单、脚本、媒体内容与参数；版本或配置变化时拒绝续跑。已完成样本直接复用，不重复追加到输出。
- 拒绝旧格式进度文件直接作为新版本的续跑依据，避免混合不同规则下的建议。
- 修正“只分析一张图却当作全部媒体已覆盖”的情况；非有限置信度归零，避免 `NaN` 进入 JSON。
- 盲测清单要求明确的未见答案、未运行 Qwen 声明；便携包校验交付源文件哈希、媒体相对路径及角色隔离。
- 加入不依赖真实数据和模型的合成演示。它验证交付工具本身，不能充当真实盲测或模型质量证据。

## 下一步如何做

协调人先核对已经发出的 21 条 v2 材料与哈希，分别收齐 A/B 独立答案，记录媒体无法访问等证据缺口，并对分歧进行真实仲裁。随后按冻结的输入、指南、参数与代码版本运行同一批模型比较，报告三分类指标、拒答比例、覆盖率、错误类型、时延与回退情况。

路线确认要回答两个问题：模型在可判定样本上是否足够可靠，以及拒答后剩下的人工工作量是否值得引入这条流程。确认前保持正式锁批和 Gold 生成关闭。涉及标签和质量的签字由真实负责人完成。
