# 标注规范变更记录

## 记录规则

- 仅记录负责人 A、B 已达成共识的标签规则变更；未决讨论不写入本文件。
- 正式标注期间每周至多发布一次修订；任何修订必须注明生效批次。
- 已锁定测试集和既有标注保留其原始 `guide_version`，不得以新规则回写。
