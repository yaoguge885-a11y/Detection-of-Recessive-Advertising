## 写作提炼

1. 先选投稿类别，再按类别限定贡献规模。短论文不是把长论文删短，而是只保留一个可验证的核心主张和足够支撑它的证据。
2. 用紧凑的问题链组织篇幅：问题与缺口 → 贡献/研究问题 → 方法或设计 → 关键结果 → 限制与意义。图表优先承载系统结构、实验对照和主要发现，正文解释其含义。
3. 篇幅越短，范围控制和证据密度越重要。少写宽泛背景和逐篇文献罗列；用最相关的工作界定差异，确保摘要、贡献声明、实验和结论互相对应。
4. 资源类稿件要把资源本身作为主要贡献：稳定可访问地址、许可、文档、质量/可复现性验证，以及维护和伦理说明。只报告“我们构建了一个数据集/工具”通常不够。
5. 模板和页数不是跨会议通用规范。每次投稿前都应重新检查当届 CFP、双盲规则、参考文献是否计页、附录政策和最终版要求。
