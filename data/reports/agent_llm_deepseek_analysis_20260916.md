## 结论

1. **LLM judge 显著优于确定性基线**：一致率 +21.9pp，κ 从 0.131 → 0.385；暗广从完全检不出（0/20）提升到 35% recall；非广 recall 从 55.9% → 80.9%，precision 达 96.5%。
2. **暗广仍是短板**：35% recall 偏低，且有 10 条暗广被归入「需复核」（模型对测评/开箱类内容倾向保守，因缺少完整视频口播/画面而选择复核）。这与暗广本身隐蔽、依赖口播与画面语境有关。
3. **需复核预测过多且命中率低**：LLM 预测 25 条需复核，但没有命中 3 条人工 manual 样本（manual 的 3 条分别被 LLM 判为 2 暗广 1 明广）。说明 LLM 的「不确定」边界与人工复核队列并不重合。
4. **改进方向**：提示词中加入对「测评/开箱类单品牌内容」更明确的暗广判定引导；引入视频口播转写/画面特征作为额外证据；用 LLM 结果作为预标注，仅把低置信度样本送入人工复核队列。
